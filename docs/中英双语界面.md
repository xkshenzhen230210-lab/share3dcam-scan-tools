# 中英双语界面（0.10.0）

在插件面板顶部选择「中文 / English」。选择立即生效，并保存在当前 Windows 用户的 SketchUp 设置中，关闭面板或重启后继续沿用。

界面保持 SHARE3DCAM 标准标识、赛尔电商中心署名和白底红黑配色；四个功能页签统一为「导入、查看 / 裁剪、绘图、工程」。英语下按钮和说明允许换行，窄面板仍可操作。

## 切换范围

- 页签、按钮、分组标题、选项、尺寸说明和操作指南。
- 点云、高斯、Mesh 的导入状态、标高读数和统计标签。
- 插件绘图工具的状态栏、尺寸标签、悬停提示和右键菜单。
- 插件弹窗、文件选择标题和已知导入错误。

切换语言保留当前页签、未提交尺寸和曲线精度；不重新导入或建立索引，也不修改模型、选择内容、源文件名、路径或几何名称。SketchUp 自带菜单、原生工具和系统文件对话框按钮仍使用各自的语言设置。未识别的第三方诊断原样显示，方便排查。

## 验证范围

- 实际 Chrome：中英两种语言 × 四个页签 × 320/360/432/640 像素宽度，共 32 种组合，无横向溢出；所有展开选项均检查了英语覆盖。
- 检查尺寸输入、表单控件身份、绘图回调参数、页签保留、动态消息、错误提示与浏览器初始语言记忆。
- SketchUp 2026：11 项原生检查通过，包括偏好持久化、工具标签、右键菜单、动态错误与模型上下文保持；真实点击切换并关闭重开面板，英语保持，最终恢复中文。
- Windows SketchUp 2024/2025 尚未实机验证。本次沿用已有转换器与 GPU 渲染器，不改变索引和工程格式。
- 原有 40 项后台回归复测通过。首次回归中一个工作进程测试读取临时 JSON 遇到 Windows `PermissionError`；该测试独立连续三次及整套复测均通过，未能稳定复现，保留为已知偶发测试问题。

## 开发检查

`translations.js` 是面板与 Ruby 共用的 UTF-8 词条表。动态词条使用 `{0}` 等占位符；原始消息保留在业务状态中，只在显示时翻译。

```powershell
node tools/check_i18n.js
node tools/check_panel.js
npm install --prefix build/bilingual/browser playwright
node tools/check_panel_browser.js
```

浏览器检查需要本机 Chrome。SketchUp 原生检查在 Ruby 控制台加载 `tests/sketchup/bilingual_test.rb`（内部开发目录为 `qa/bilingual_test.rb`），再调用 `BilingualTest.run` 并提供结果 JSON 的绝对路径。
