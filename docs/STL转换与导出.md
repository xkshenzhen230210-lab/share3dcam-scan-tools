# SHARE3DCAM 扫描绘图助手｜STL 转换与导出

赛尔电商中心 · Windows 0.11.1 · SketchUp 2024–2026

在 SketchUp 的「扩展程序管理器」安装新版 RBZ，重启 SketchUp，打开「赛尔点云绘图助手」。面板顶部可切换中文和英文。

1. **STL 导入 SU**：进入「导入 → Mesh 网格」，先展开「OBJ / STL 输入单位与轴向」，按来源选择单位和向上轴。常见打印文件用毫米。点击「导入网格组件」，选择 STL；导入后用卷尺核对已知尺寸。
2. **GLB / OBJ 直接转 STL**：在同一张卡片展开「STL 转换与导出」，选择输出单位，默认毫米。点击「GLB / OBJ 转 STL」，选择源文件和保存位置。OBJ 使用所设输入单位与轴向；GLB 按米、Y 向上读取。两种输出皆为 Z 向上。
3. **把 SU 模型导出为 STL**：退出群组或组件的编辑状态，选中要导出的面、群组或组件，再点击「导出选中几何」。如只要新画的实体，选择时避开原 Mesh 组件。

STL 只保存三角面，没有单位、贴图、颜色或材质。接收者应按约定单位打开。点云和高斯是绘图参照，先在 SU 画成几何才能导出。转换不会自动封洞或修复非流形网格；3D 打印前检查实体是否闭合。

保存收拢参照时，新版会阻止不同单位、范围或布局的索引覆盖同名旧工程。如果提示重名，请换一个工程名。
