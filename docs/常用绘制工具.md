# 常用绘制工具

在插件的「绘图」页使用。扫描参照应保持可见；先裁掉干扰、核对地面标高，再开始绘制。

| 工具 | 点云 / 高斯上的操作 | 尺寸框输入 |
|---|---|---|
| 矩形 | 捕捉第一个角点，再选对角点；长宽沿模型 X/Y 方向 | `3m,200mm`，也支持中文逗号；输入正数，鼠标决定所在象限 |
| 圆 | 捕捉圆心，再选半径点 | `500mm` 表示半径，直径为 1m |
| 正多边形 | 捕捉中心，再选一个顶点方向 | 输入中心到顶点的半径；默认六边形，可在「尺寸输入与曲线精度」修改 |
| 圆心圆弧 | 捕捉圆心，确定起点和半径，再沿逆时针选终点方向 | 第二步可输 `1m`；第三步输 `90` 或 `90度`，角度须大于 0 且小于 360 |

首次点击必须捕捉可见的扫描点。起点确定后，其余位置允许落在已建立的水平绘图平面上，所以扫描孔洞不会阻止完成轮廓。红框显示实际落点。开启「俯视平面描图」时使用指定标高；关闭时取首点标高，这四种扫描轮廓仍保持水平，不跟随扫描噪声产生斜面。

圆默认 48 段；可设为 12–360 段。多边形可设为 3–64 边。圆弧按整圆基准段数和实际角度分配分段。调整精度后重新点击工具开始下一次绘制；已完成的几何不会自动改变。

按 Esc 清除本次尚未完成的预览；右键可重选起点或结束工具。每个完成的轮廓是独立原生群组，支持 SU 的撤销、保存和后续编辑。

## 成面后建立实体

圆、矩形和正多边形自动生成朝上的底面。完成后群组会被选中：

1. 点「推拉已画轮廓」进入群组并启用原生推拉；单击面，移动鼠标确定方向，输入 `2.8m` 等带单位的高度。建议用斜视角观察方向。
2. 或点「输入高度向上拉伸」，在对话框输入米数。该操作沿全局蓝轴向上生成闭合实体，适合从俯视底面建立墙段或圆柱。
3. 原生推拉完成后退出群组编辑，再画下一个轮廓。圆弧是开放曲线，不自动成面；需要用边补齐闭合轮廓才能推拉。

高斯不透明度为 100% 时可能遮住与扫描地面重合的底面。在「查看 / 裁剪」降低不透明度，可同时查看参照与新几何。

## Mesh 和原生修改工具

没有活动点云/高斯参照时，这四个按钮启动 SU 原生矩形、圆、正多边形和圆心圆弧，可吸附 Mesh 顶点、边和面；遵循 SU 自身的平面推断和尺寸输入。

「原生直线」和「原生偏移」用于已有 SU 几何。原生偏移需要当前编辑层级中的面或相连边；它们不会直接捕捉高斯或点云，扫描描线请使用「捕捉描线 / 成面」。

## 开发验证

SU 2026 内的原生几何回归覆盖圆面、半径精度、竖直圆柱、矩形长宽和象限、正多边形、ArcCurve、无效输入、取消、绘图标高、扫描缺口落点和隐藏参照。测试只产生临时几何并清理；不会覆盖原有模型文件。

开源源码中的验收脚本为 `tests/sketchup/shape_tools_test.rb`，需在已加载插件的 SU Ruby 控制台运行：

```ruby
root = UI.select_directory(title: '选择开源源码目录')
if root
  load File.join(root, 'tests/sketchup/shape_tools_test.rb')
  output = File.join(Sketchup.temp_dir, 'shape_tools_result.json')
  ShapeToolsTest.run(output)
  puts File.read(output)
end
```

接口依据：[SketchUp Entities](https://ruby.sketchup.com/Sketchup/Entities.html)、[Tool](https://ruby.sketchup.com/Sketchup/Tool.html)、[send_action](https://ruby.sketchup.com/Sketchup.html#send_action-class_method)。
