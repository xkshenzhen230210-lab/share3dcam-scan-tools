# 构建与架构

## 环境

已验证 Python 3.12 x64、Windows、Visual Studio 2022 Build Tools、Windows SDK、D3D11 可用显卡。依赖版本见 requirements-lock.txt。

build_native.py 使用 vswhere 查找 C++ Build Tools。自定义安装时可设置 `VCVARS64` 为 vcvars64.bat 的实际路径，之后执行构建命令。

## 源码结构

- extension：SketchUp Ruby 扩展、中文 HtmlDialog、捕捉及绘图工具。
- converter：Python 导入转换、完整索引、查询与导出后端。
- native：独立 D3D11 点云/高斯渲染器、原始点编号拾取、多边形裁剪。
- tests：临时生成数据的回归测试。原生测试需要先构建 DLL。
- tools：本机构建、许可证收集与打包脚本。

## 构建

先安装 README 中的依赖和 C++ 工具。执行 `python tools/build.py` 完成全构建。

只检查原生路径时：

```powershell
python tools/build_native.py
python -m unittest discover -s tests -v
```

只修改 Ruby/HTML，且已有转换器和渲染 DLL 时，可以运行 `python tools/repack_extension.py`。没有编译运行时的干净源码目录不能直接使用此快捷打包步骤。

生成物为 extension/share_pointcloud/bin 下的转换器与 DLL，以及 release 下的 RBZ。生成物不进入 Git。

## 数据与坐标

源文件转换为局部坐标，导入原点偏移保存在 cloud.json。普通点云完整索引为 schema 2；标准高斯索引为 schema 3。SU 使用英寸，界面尺寸使用米。

原生渲染器使用 SU 当前投影/视图矩阵，将局部源坐标映射至视窗。拾取返回深度可见的源编号和原始坐标。自由裁剪使用圈选时的精确矩阵建立原始点位掩码，之后转动视图不改变保留的点位。

高斯近相机、远离视锥的协方差投影导数会受扩展视窗约束，防止离屏高斯扩大成全屏黑斑；实际点中心投影与深度保持原公式。

## 维护

不要在 SU 正加载旧 DLL 时覆盖同名文件。修改原生 ABI 或发布新 DLL 时，应同步更新 Ruby 绑定、构建脚本、原生测试和打包排除列表。

不要在 Overlay 绘制回调中修改模型。相机/几何变更经现有 safely 队列执行。不同 SU 版本应分别实测；未通过的格式或硬件不可写为已支持。
