# SHARE3DCAM 扫描绘图助手 · M 系列 Mac

赛尔电商中心｜0.11.0-mac.1｜中英双语测试版

## 适用范围与验证状态

仅支持 Apple Silicon（M 系列芯片），请使用原生启动的 SketchUp，目标版本为
2024–2026。Intel Mac 和通过 Rosetta 运行的 SU 不支持。
本次构建与自动化环境为 macOS 15 / arm64，其他 macOS 版本未实机验证。

已在 Apple Silicon 云端完成原生编译、独立转换器格式测试及 Metal GPU 回归。
**尚未在 Mac 版 SketchUp 内验收安装、现场捕捉、原生推拉及保存复开。**
这是可安装的测试包，不能标为已经完成客户验收的正式版。
原生文件使用临时签名，尚未进行 Apple 开发者签名与公证。

## 安装

1. 完整解压交付 ZIP；不要解压里面的 `.rbz`。
2. 打开 Mac 版 SU 的“扩展程序管理器”，点“安装扩展程序”，选择本包 RBZ。
3. 重启 SU，打开“赛尔点云绘图助手 / SHARE3DCAM Scan Tools”。
4. 面板顶部选“中文”或“English”；语言选择会保存。
5. 先用小样本核对尺度、视图跟随、捕捉和保存，再处理大项目。

客户电脑无需另装 Python、CUDA 或 Windows 模拟环境。

## 功能与 Windows 版的对应

| 功能 | Mac 实现 |
|---|---|
| 点云导入 | LAS、LAZ、普通 PLY、XYZ、TXT、PTS；完整索引与已有索引打开 |
| 全量显示 | Metal GPU 常驻数据；移动和静止均提交全量，不切十万点预览 |
| Mesh 导入 | GLB、OBJ；保留材质与贴图，生成原生组件 |
| 高斯导入 | 标准 3DGS PLY、已有高斯索引；主视窗显示，不设独立查看器 |
| 参照整理 | 移动、转正、立体剪切盒、水平切片、自由圈选裁剪与恢复 |
| 捕捉绘图 | 标高拾取、测距、描线与成面、矩形、圆、多边形、圆弧、向上拉伸 |
| 工程管理 | SKP 保存、参照索引收拢与复开逻辑沿用现有版 |
| 中英文 | 共用同一份翻译表、同一套面板与绘图代码 |

以上是代码功能范围，不表示 Mac 版 SU 内逐项验收已通过。
Windows 的“导入兼容模式”是专用 CPU 调度选项，Mac 上不适用，按钮禁用。
普通点云上限一亿点，标准高斯上限两千万个；实际还受统一内存及 Metal 单缓冲区限制。
资源不足时提示失败，不自动换成抽稀参照。OSGB 不在现有导入范围内。

## 三类数据怎么用

**点云：**“导入 → 点云 → 选择点云文件”，确认单位，选择本地可写的索引目录。
转换完成后“定位全部”；再次使用可直接“打开已有索引”。保留完整索引文件夹。

**Mesh：**“导入 → Mesh 网格 → 导入网格组件”。OBJ 要带齐 MTL 和贴图。
先看清范围、纹理和尺度，把扫描组件与新画墙体分组管理，不要炸开全部扫描面。

**高斯：**“导入 → 高斯 → 导入到 SU 主视窗”；标准 3DGS PLY 与普通点云 PLY
不是同一种数据。已有索引可从高斯区域直接打开完整文件夹。

**绘墙：**先核对干净地面标高，再看清墙角和洞口；开启同标高描图，画闭合的
有厚度墙带。用“闭合并向上拉伸”或“输入高度向上拉伸”，按米输入高度。
检查竖直方向及墙底位置。原生 P 推拉需进入底面所在群组。
不要把墙身切片高度当墙底标高，也不要追着扫描杂点反复折线。

**裁剪：**立体剪切盒限定空间，Esc 保留剪切；水平切片只改变显示。
自由裁剪固定视角后逐点圈选，Enter 应用、Backspace 回退、Esc 取消。
它沿当前视线贯穿，不是网格布尔切割。

## 保存与客户测试

点云/高斯工程要携带 `.skp` 与同名“_点云数据”目录；内部文件不可单独改名。
已有索引格式与 Windows 版共用。Mac 临时查询文件位于用户缓存目录，原数据不改写。
中文和带空格路径已有转换器自动测试，不要求所有目录必须英文。

Mac 版 SU 最终验收请记录：

- 原生 arm64 SU 版本与 macOS 版本；中英文切换后输入、工具状态正常。
- Retina 缩放、窗口改变大小后，鼠标捕捉仍落在可见点位。
- 点云/高斯随相机移动；原生墙体在前后位置的遮挡正确。
- 墙带闭合能拉起，圆与圆弧尺寸正确；裁剪及恢复结果稳定。
- 完整保存、退出、复开，再换目录复制一次，实体与参照都能恢复。

Windows 0.10.0 教学中曾遇高斯复开显示层错误 `SUModelCreateOverlay:15`；
目前不能据此声称 Mac 上已修复或必然出现。Mac 的对应路径仍需要 SU 实机验证。
